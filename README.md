DC Transportation Data Analytics | Python, Tableau & ArcGIS Pro

Project Overview

This project was completed as part of the Data Scientist technical assessment for the District Department of Transportation (DDOT). The goal was to analyze construction permits, roadway maintenance activities, and transportation data in Washington, DC.

I used Python, Tableau, and ArcGIS Pro to clean and process datasets, perform geospatial analysis, and create visualizations that support data-driven decision-making.

Tools & Technologies

Python: Pandas, data cleaning, merging, filtering, and analysis

Tableau: Interactive dashboards and data visualization

ArcGIS Pro: GIS mapping, spatial joins, and geospatial analysis

Google Colab: Python programming and data processing

JSON & CSV: Data preparation and exporting results

1. Python – Data Processing and Analysis

I used Python to combine multiple JSON datasets, clean missing values, remove duplicates, and standardize date fields. I filtered construction permits based on specific requirements and calculated approval times in business days, excluding weekends and applicable DC holidays.

I also worked with public space occupancy permits to analyze roadway functional classifications and prepared CSV outputs for further analysis.

2. Tableau – Permit Approval Dashboard

I created an interactive Tableau dashboard to analyze construction permit approval performance during Fiscal Year 2026.

The dashboard includes overall approval performance, comparisons by construction work type and DC ward, monthly trends, and approval time distributions.

Key Findings:

Total unique permits: 1,225

Average approval time: 37.69 business days

Landscaping had the longest average approval time at 74 days.

Excavation had the largest permit category, with 1,085 permits.

3. ArcGIS Pro – Geospatial Analysis

I used ArcGIS Pro to analyze construction permits, roadway subblocks, and Cityworks maintenance service requests.

My work included filtering records, snapping permit locations to roadway centerlines, performing spatial joins, calculating permit and service request counts, and identifying roadway segments with both permit activity and open maintenance requests.

I created a map and packaged the GIS project for review.

Project Outcomes

This project strengthened my practical skills in Python, GIS, Tableau, data cleaning, spatial analysis, and visualization. It also gave me experience working with real-world government datasets and presenting analytical findings in a clear, understandable way.
